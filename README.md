# 💼 Job Portal

A full-stack **Job Portal application** built using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)**.

This application provides a platform where **Job Seekers** can discover and apply for jobs, while **Employers** can create and manage job listings, review applicants, and manage their company profiles.

The project also implements **JWT-based authentication**, **role-based access control**, resume management, job applications, saved jobs, and responsive dashboards.

---

## 🚀 Features

### 🔐 Authentication & Authorization

- User registration and login
- JWT-based authentication
- Role-based access for:
  - Job Seekers
  - Employers
- Protected routes for authenticated users
- Role-based access control for employer-specific features

### 👨‍💻 Job Seeker Features

- Browse available job listings
- Search for jobs
- Filter jobs by category, location, and company
- View detailed job information
- Apply for jobs
- Upload and manage resumes
- Track application status
- Save/bookmark jobs for later
- Manage personal profile

### 🏢 Employer Features

- Employer dashboard
- Create new job listings
- Edit existing job listings
- Delete job listings
- Close job listings
- Manage posted jobs
- View applicants for posted jobs
- View applicant information
- Download applicant resumes
- Manage company profile
- Add company name, description, and logo

### 📱 Responsive Design

- Responsive layout for desktop, tablet, and mobile devices
